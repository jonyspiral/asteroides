1 · Objetivo→ 2 · Resolver contexto→ 3 · Rector / Work Unit→ 4 · Autorizar→ 5 · Agente razona→ 6 · Project Control enruta→ 7 · Executor / MCP actúa→ 8 · Receipt→ 9 · Reconciliar
Principio rector: Asteroides Core sabe qué es y cómo se relaciona cada elemento; Project Control sabe qué se está haciendo y hasta dónde está autorizado; Harness define cómo debe hacerse dentro de cada proyecto; el agente razona; y Executor/MCP materializa el efecto en el runtime correcto.
