# Visión del ecosistema

Asteroides es un ecosistema de capacidades para transformar necesidades reales de negocio en proyectos, software, automatizaciones, integraciones y operaciones digitales gobernadas.

## Tesis
El producto no es solamente “Asteroides” como plataforma. El valor principal aparece en los **subproductos y oportunidades de negocio** que pueden construirse reutilizando contexto, gobierno, agentes, conectores y runtimes comunes.

## Organizaciones consumidoras iniciales
- Asteroides.
- Spiral Shoes.
- Cumbres & Mareas.
- futuros clientes internos o externos.

## Principios
1. Una experiencia simple hacia el usuario.
2. Separar componentes sólo cuando cambian autoridad, runtime o riesgo.
3. Contexto compartido; lógica de negocio local.
4. Agentes reemplazables y sin autoridad propia.
5. GitHub y receipts como evidencia durable.
6. MVP completo antes que catálogo amplio de capacidades incompletas.
