# Decisiones rectoras

Este directorio conserva decisiones que afectan a más de un proyecto o definen fronteras del ecosistema.

## Decisiones vigentes iniciales

1. `jonyspiral/asteroides` es el repo madre del Master Plan y del Core v0.1.
2. Asteroides Core aporta contexto, identidad, relaciones y herencia; no ejecuta producción.
3. Project Control MCP conserva el gobierno del trabajo activo y el routing.
4. Harness conoce y protege el proyecto local; no replica el mapa completo del ecosistema.
5. Se hereda contexto, no autoridad.
6. Agentes/modelos son reemplazables y no son fuente durable de verdad.
7. Executor interno y MCP/adaptadores externos permanecen especializados por frontera de confianza.
8. GitHub conserva código e historia durable del trabajo técnico; Drive/knowledge stores conservan activos no-código cuando corresponda.
9. Una experiencia de producto puede ser modular por dentro; no introducir servicios separados si no cambia autoridad, runtime o riesgo.
10. El MVP debe cerrar recorridos completos antes de ampliar el catálogo de capacidades.

Las decisiones nuevas deben registrar fecha, alcance, razón y proyectos afectados.
