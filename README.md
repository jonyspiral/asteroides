## Principio rector

Asteroides no es un único producto. Es una **fábrica de capacidades** que permite crear productos y servicios para Asteroides, Spiral Shoes, Cumbres & Mareas y futuros clientes internos o externos.

- **Asteroides Core** sabe qué es cada elemento y cómo se relaciona.
- **Project Control MCP** sabe qué se está haciendo, con qué autorización y cuál es el siguiente paso.
- **Asteroides Harness** define cómo debe trabajarse dentro de cada proyecto.
- **Agentes** como ChatGPT, Codex o Claude razonan, desarrollan y usan herramientas; no poseen autoridad propia.
- **Asteroides Executor MCP** materializa capacidades internas allowlisted.
- **MCP/adaptadores externos** materializan capacidades sobre proveedores externos.
- **GitHub** conserva la historia durable del trabajo técnico.

La separación técnica se introduce sólo cuando cambian la autoridad, el runtime o el riesgo. No se agregan MCPs, servicios, bases o coordinadores por anticipación.
